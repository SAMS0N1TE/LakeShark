# Hand-written Portuguese -> English data for mt_xlate_lang (MESHTASTIC app).
# Written for this app; GPL-3.0-or-later like the rest of LakeShark.
# gen_xlate_lang.py reads it with the Wiktionary lexicon and writes ../lang/pt.bin
# (and the phrasebook and detection words into ../mt_xlate_langs.h).
# Brazilian chat first: você, a gente, tá, pra, vc, blz, kkk.
# Fields are separated by " | ". Keys may carry accents; the generator folds them
# (lower case, accents off) and keeps whether the key was written with one, so
# "é" (is) and "e" (and) stay apart when the accent is typed.
#
# @func  key (one to five words) | CLASS[:flags] | english [| english standing alone]
#   DET: def, pl, poss, neg, q     PRON: person 1-6 (English: 1 I, 2 you, 3 he, 4 we, 5 you, 6 they),
#   alt = object form              CLIT: object pronoun before the verb, english = object
#   NEG: before the verb           NEG2: after the verb, english in a negative clause | alone
#   PREP: the = carries "the"      CONJ: sub = subordinate clause
#   EXIST: there is (pl: are, neg: isn't)   CL: a whole clause   PH, INTJ, ADV, Q, PRONX, NUM, SKIP
#   A = only as the whole clause, S = only at the start of a clause
# @abbr  chat spelling | what it stands for (Portuguese words)
# @verbs lemma | roles (BE HAVE PROG GOING CAN WANT MUST SHOULD WILL MAY PERFBE IT NEED)
# @lex   lemma | POS[:m,f,n,u] | gloss   (u: English noun without a plural)
# @drop  lemma | POS
# @book  English line of the phrasebook (xlate_es_en.txt) | Portuguese to send
# @detect word | weight 1-15 (chat words for language detection)
