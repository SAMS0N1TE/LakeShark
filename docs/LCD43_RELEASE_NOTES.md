# Optional Touch-LCD-4.3 build

The Waveshare ESP32-P4-WIFI6-Touch-LCD-4.3 configuration is experimental and available for owners who want to try it. T-Display-P4 is the primary display target.

The LCD-4.3 configuration uses its 480 x 800 display and 32 MB flash layout. It includes receiver controls for P25 Phase 1, FM, POCSAG, ADS-B and recording, plus Flipper control.

See [first installation](LCD43_FIRST_FLASH.md) and the [quick start](LCD43_QUICKSTART.md).
