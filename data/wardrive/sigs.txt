# WARDRIVE signatures: what a heard device is.
#
# Copy this file to /sdcard/wardrive/sigs.txt to change or add signatures.
# The firmware carries the same rows built in; a row here with the same id
# replaces the built-in one, a new id adds one, and "id|off" turns one off.
# WARDRIVE reads the file each time its screen opens.
# SWEEP and WARDRIVE share this table; SWEEP folds the rows of an old
# /sdcard/sweep/rules.json in as ids sweep-1, sweep-2... ("sweep-2|off" here
# turns one off).
#
# One signature per line, seven fields split by '|':
#
#   id | tags | kinds | alert | label | patterns | source
#
#   id        short and stable, letters, digits and '-'
#   tags      what it is, joined by '+': ALPR CAMERA BODYCAM POLICE TRACKER
#             DRONE VEHICLE SKIMMER HACKTOOL GLASSES SENSOR WATCH
#   kinds     which radios it applies to, joined by '+': WIFI BLE CELL DRONE
#             RF AIR LORA, or * for all
#   alert     0 log only (a lead, never alerts), 1 alert, 2 alert, high
#             confidence (listed first)
#   label     what the screen calls it, up to 23 characters
#   patterns  any one of these matches, split by ',':
#               name:GLOB   the Wi-Fi network or Bluetooth name, whole, any
#                           case. * any run, ? one character, # one hex
#                           digit, % one decimal digit, \ takes the next
#                           character as it is (\, for a comma)
#               oui:AABBCC  the first three bytes of the address
#               mac:AABBCCDDEEFF  one exact address (your own watch list)
#               co:NNNN     Bluetooth company ID (hex); co:NNNN/BB also wants
#                           BB as the first byte after the ID
#               uuid:NNNN   16-bit Bluetooth service UUID (hex); uuid:NNNN/BB
#                           also wants BB as the first byte of its data
#               uuid:12345678-1234-5678-9abc-123456789abc
#                           a 128-bit Bluetooth service UUID
#               any         every device of the row's kinds
#   source    where the pattern comes from, shown on the HUNT detail page
#
# Company IDs and service UUIDs need the Bluetooth feed to report them; until
# it does, BLE rows match by name and address only.
#
# Sources. Only identifiers published by these are listed; each row names its
# own. LakeShark is GPL-3; the projects below are MIT, Apache-2.0, GPL-3 or
# AGPL-3 (identifiers only, which are facts, not code), credited here.
#   flock-you        github.com/colonelpanichacks/flock-you (MIT): main.cpp,
#                    datasets/firmware_derived_signatures.md
#   flock-you-esp32  github.com/simeononsecurity/flock-you-esp32 (Apache-2.0)
#   ESP32Marauder    github.com/justcallmekoko/ESP32Marauder (MIT): WiFiScan.cpp
#   ouispy           github.com/colonelpanichacks/ouispy-detector (MIT):
#                    BLEOUIs.md, WiFiOUIs.md
#   lookout.py       github.com/judcrandall/lookout.py
#   BT SIG           Bluetooth SIG assigned numbers (company identifiers,
#                    member and SDO UUIDs), bitbucket.org/bluetooth-SIG/public
#   vehicle-command  github.com/teslamotors/vehicle-command (Apache-2.0):
#                    pkg/connector/ble/ble.go
#   trifinite        trifinite.org, "TEMPA" CanSecWest 2022 slides (Tesla)
#   carscanner       carscanner.info/wifi (ELM327 Wi-Fi adapters)
#   flipper fw       github.com/flipperdevices/flipperzero-firmware (GPL-3)
#   deauther         github.com/SpacehuhnTech/esp8266_deauther (MIT): A_config.h
#   pwngrid          github.com/evilsocket/pwngrid (GPL-3): wifi/defines.go
#   Hak5 docs        docs.hak5.org, WiFi Pineapple setup

#   Skimmer Scanner  github.com/sparkfunX/Skimmer_Scanner (SparkFun)
#   USENIX Sec 19    Bhaskar et al., "Please Pay Inside" (skimmers), slides
#   Cradlepoint      IBR600 and MBR1400 user manuals (default SSID)
#   Ring             ring.com support, Video Doorbell setup mode

#
# Left out on purpose: the community "Flock OUI" list (about 30 prefixes) is
# mostly Liteon, USI, Espressif and Silicon Labs radios, Flock-style names in
# about 2% of sightings (simeononsecurity.com flock-finder OUI audit, 2026);
# listing them would call every smart plug a plate reader. Only Flock's own
# IEEE prefix is here.
